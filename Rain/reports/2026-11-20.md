### 4. สิ่งที่ได้เรียนรู้วันนี้
- **ระบบ / เครื่องมือ / ขั้นตอนการทำงาน:**
  - ได้เรียนรู้เรื่อง Monorepo ว่าแพ็กเกจต่างๆ (`@mango/shared`, `@mango/portal`, `@mango/admin`, `@mango/api`) เชื่อมโยงกันอย่างไร
  - ได้รู้จักคำสั่ง Prisma (`generate`, `migrate`, `seed`) ว่าใช้สร้างและอัปเดตโครงสร้างฐานข้อมูลอย่างไร
  - ได้เข้าใจการทำงานของ `embedded-postgres` ว่าช่วยจำลอง PostgreSQL บนเครื่อง Windows ได้โดยไม่ต้องลง Docker Desktop
- **ศัพท์หรือแนวคิดใหม่ที่เพิ่งรู้:**
  - **DTO (Data Transfer Object):** โครงสร้างข้อมูลที่ใช้คุยกันระหว่างหน้าบ้าน (Frontend) กับหลังบ้าน (Backend) ถ้าสองฝั่งไม่ตรงกัน ระบบจะพัง
  - **Prisma Schema & Migration:** การแปลงโค้ดโครงสร้างข้อมูลให้กลายเป็นตารางจริงใน Database
  - **Loopback & PNA:** การที่เว็บหน้าบ้านคุยกับโปรแกรมที่รันบนเครื่องตัวเองผ่านพอร์ต 127.0.0.1 อย่างปลอดภัย

### 5. สิ่งที่ยังไม่เข้าใจ / ข้อสงสัย
- เรื่องการทำงานของ WireGuard และการส่ง Connect Ticket ผ่าน Agent บนเครื่อง ยังต้องศึกษาต่อเมื่อได้ทดลองเชื่อมต่อ VPN จริง
- การตั้งค่า Environment ใน Monorepo ในบางกรณีที่รันคำสั่งข้ามโฟลเดอร์ ว่ามีวิธีทำให้ Prisma มองเห็น Root `.env` ได้อัตโนมัติอย่างไรบ้าง

### 6. ปัญหา / อุปสรรค (ถ้ามี)
- **ปัญหาที่พบ 1:** รัน `npm run db:migrate` แล้วแจ้งว่าหา `DATABASE_URL` ไม่เจอ
  - *สาเหตุ:* ตัว Prisma CLI รันในโฟลเดอร์ `Sobree/api` ซึ่งเดิมไม่มีไฟล์ `.env` (ไฟล์อยู่ที่ Root นอกสุด)
  - *วิธีแก้ไข:* คัดลอกไฟล์ `.env` เข้าไปไว้ใน `Sobree/api` ทำให้ Prisma โหลดค่าตัวแปรได้ถูกต้อง
- **ปัญหาที่พบ 2:** รัน `npm run db:start` แล้ว Node แจ้งว่าหา `embedded-postgres/index.js` ไม่เจอ
  - *สาเหตุ:* แพ็กเกจ `embedded-postgres` ใน `node_modules` โหลดมาไม่สมบูรณ์ (โฟลเดอร์ว่าง)
  - *วิธีแก้ไข:* ติดตั้งแพ็กเกจ `embedded-postgres@16.16.0-beta.19` ใหม่ และรันสคริปต์ลิงก์ไฟล์สำหรับ Windows ทำให้ใช้งานได้ปกติ
